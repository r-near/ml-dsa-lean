# ML-DSA verify with the branchless 4-way ExpandA parse, 2026-11-07

Branch `fv-p2a` (the 4-way sampler stores each lane's rate bytes and parses them branchlessly, `src/sampling.rs`).
Built and run by `bench/fast-verify.sh` (nearcore profile and target features; `avx2` = the dispatched proved path, `v3` =
`-C target-cpu=x86-64-v3`). Same machine as [2026-11-06](../2026-11-06.md) (AMD EPYC 9B14, Zen 4, KVM guest, 60 vCPUs).
Pinned to the idlest core pair (cpu 1 for the default toolchain, cpu 3 for 1.95.0); load average 0.92 at the start of the
run and 1.00 at its end (the benchmark itself). Medians of 15 rounds, microseconds. The raw
log is [`fast-verify-p2a.log`](2026-11-07-p2a/fast-verify-p2a.log).

Before this change (same box, same flags, ML-DSA-65, `avx2` column): verify 74.3-76.3, `verifying_key` 47.4-48.4 (five
runs of the commit before the branchless parse). Now: verify 66.1 (default toolchain) / 68.1 (1.95.0), `verifying_key`
40.0 / 40.6.
